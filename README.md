# DemuxMuse

DemuxMuse는 밴드 연습용 Android 앱입니다. 곡을 보컬·드럼·베이스·기타 등 악기별 스템으로 나눠서, 내 파트만 빼고 나머지 반주에 맞춰 합주하듯 연습할 수 있습니다.

## 주요 기능

- **라이브러리** — 가져온 곡과 분리된 스템을 한곳에서 관리
- **＋ 버튼으로 가져오기/분리** — 오디오 파일을 가져와 악기별 스템으로 분리
- **믹서 · 루프** — 스템별 볼륨/뮤트/솔로, 원하는 구간 반복 재생
- **백그라운드 재생** — 화면을 끄거나 다른 앱을 써도 연습 계속

## 설치

1. [Releases](https://github.com/SangwonSUH/DemuxMuse-android/releases)에서 최신 `DemuxMuse-x.y.z.apk`를 내려받습니다.
2. Android 설정에서 해당 앱(브라우저/파일 앱)의 **출처를 알 수 없는 앱 설치**를 허용합니다.
3. APK를 열어 설치합니다.

> 현재는 개인/테스터 배포 빌드이며 Play 스토어에는 올라가 있지 않습니다. 각 릴리스에 SHA-256 체크섬(`SHA256SUMS`)이 함께 첨부되어 있습니다.
